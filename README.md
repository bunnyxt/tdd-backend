# tdd-backend

## Status

The production backend is the legacy Spring service in
[`v2_spring_backend/tdd`](v2_spring_backend/tdd). It receives only minimal,
security-focused maintenance while its replacement is designed.

The GraphQL experiment in
[`v3_graphql_backend/tdd-backend-graphql`](v3_graphql_backend/tdd-backend-graphql)
is **deprecated**. It is not a supported API, must not be deployed, and is not
a starting point for the replacement backend. Its source and lockfile remain
only as historical reference; dependency alerts in that directory are not
evidence that a v3 service is running.
